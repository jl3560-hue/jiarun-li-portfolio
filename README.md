# Jiarun Li — Personal Portfolio

Portfolio website for Jiarun Li, Management student at Rutgers Business School.

## GitHub Pages setup
1. Upload `index.html` and `style.css` to a public GitHub repository.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then Save.
5. Submit both the public repository URL and the generated live website URL.
